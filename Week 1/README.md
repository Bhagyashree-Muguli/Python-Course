# Week 1: Python Basics 🐍

## Description
This week covers the fundamental concepts of Python programming, including variables, data types, input and output, type casting, operators, strings, lists, tuples, sets, dictionaries, and Boolean values.

2. Variables
3. Data Types
4. Input and Output
5. Type Casting
6. Operators
7. Strings and String Methods
8. Lists and List Methods
9. Tuples and Tuple Methods
10. Sets and Set Methods
11. Dictionaries and Dictionary Methods
12. Boolean Values
13. Comparison Operators
14. Membership and Identity Operators
